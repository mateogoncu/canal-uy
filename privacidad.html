Política de privacidad de canal-uy

Vigente desde el 16 de noviembre de 2026.

canal-uy es una aplicación de uso interno del canal de YouTube “Uruguay en contexto”. La usa únicamente el responsable del canal, desde su propia computadora, para publicar los videos del canal.

Qué datos de Google usa

Con la autorización del responsable del canal, la aplicación accede a la API de datos de YouTube para:

  • subir videos, títulos, descripciones y miniaturas al canal propio (permiso youtube.upload);
  • leer el nombre y el identificador del canal propio y el estado de sus videos (permiso youtube.readonly).

No accede a datos de otros usuarios de YouTube o de Google, ni a correos, contactos, archivos u otra información de la cuenta.

Dónde se guardan

El token de autorización y la información de los videos se guardan solo en la computadora del responsable del canal, en archivos con acceso restringido. No hay servidores propios ni bases de datos en internet.

Con quién se comparten

Con nadie. Los datos no se venden, no se transfieren a terceros y no se usan con fines publicitarios. Solo viajan entre la computadora del responsable y los servidores de Google, para cumplir la función de publicar videos.

El uso que canal-uy hace de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, la aplicación deja de poder publicar y el token guardado queda inutilizable; también se puede borrar de la computadora.

Servicios de YouTube

Al usar esta aplicación se usan los servicios de API de YouTube, sujetos a las Condiciones del servicio de YouTube y a la Política de privacidad de Google.
